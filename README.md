# Redplate
RedPlate is a food ordering system developed for the Batangas State University canteen. It streamlines the ordering process for students while helping stall owners efficiently manage orders. The system applies Data Structures and Algorithms concepts to optimize data handling, search operations, and overall performance.

# Redplate

A restaurant ordering and management system built with Python and Flask.

## Features (planned)
- Customer menu and ordering
- Kitchen order view
- Admin menu management

## How to run
1. Install Flask: `pip install flask`
2. Run the app: `python app.py`
3. Open http://127.0.0.1:5000 in your browser
